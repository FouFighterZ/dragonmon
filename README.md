# DragonMon

A fan-made, Pokémon-style Dragon Ball game: clone fighters, train them and follow the story from the Saiyan saga to the latest Dragon Ball Super arcs.

**Download:** grab `DragonMon-Setup-x.y.z.exe` from the [latest release](https://github.com/FouFighterZ/dragonmon/releases/latest) and run it (Windows). Once installed, the game updates itself automatically every time a new version is published.

This repository only hosts the installers. Fan game, not affiliated with the Dragon Ball rights holders.
